# 본문 컴포넌트

마크다운 본문에서 바로 쓰는 include 세 가지다. 셋 다 본문 폭(720px) 안에 들어가고,
스타일은 `_sass/_content.scss` 에 있다. 색은 테마 토큰을 쓰므로 다크·라이트 모두 따라간다.

구분자는 공통이다. 항목은 파이프(`|`)로, 값과 라벨은 콜론(`:`)으로 나눈다.
항목 앞뒤 공백은 자동으로 잘린다.

## 1. TL;DR 박스 — `tldr.html`

글의 결론을 첫 h2 바로 위에 둔다. 면접관은 스크롤하지 않는다는 전제에서 쓰는 자리다.

```liquid
{% raw %}{% include tldr.html items="화면 기준 QA 케이스 80건을 API 계층에서 재현했다|시트에 없던 결함 3건을 배포 전에 잡았다|케이스 변환은 에이전트에게, 검증 계층 선택은 사람이 했다" %}{% endraw %}
```

항목 수에 제한은 없지만 세 개 안쪽이 읽힌다.

## 2. 핵심 수치 스트립 — `metrics.html`

결과 절의 숫자를 한 줄로 늘어놓는다. 값은 강조색으로 크게, 라벨은 작게 나온다.

```liquid
{% raw %}{% include metrics.html data="80건:재현·검증한 QA 케이스|7건:새로 발견한 결함|40분 → 4분:회귀 1회 수행 시간" %}{% endraw %}
```

- 값이 6자를 넘으면 글자 크기가 자동으로 줄어 칸 안에서 잘리지 않는다.
- 값의 크기가 칸마다 달라도 라벨의 윗선은 한 줄로 맞는다.
- 라벨에 콜론이 들어가도 된다. 첫 콜론까지만 값으로 읽는다.
- 칸은 화면 폭에 따라 줄바꿈된다. 셋이나 넷이 적당하다.

## 3. Before / After 비교 — `compare.html`

바뀌기 전과 후를 나란히 놓는다. 각 값의 **첫 항목이 라벨**이고 나머지가 목록이다.

```liquid
{% raw %}{% include compare.html
   before="이전|화면을 보고 사람이 클릭|케이스마다 20분|회귀는 릴리스 직전 한 번"
   after="이후|API 계층에서 자동 실행|전체 4분|커밋마다 회귀" %}{% endraw %}
```

오른쪽 카드가 강조색 테두리를 받는다. 개선된 쪽을 `after` 에 둔다.

## 주의

- 마크다운 파일 안에서 include 앞뒤로 빈 줄을 둔다. 붙여 쓰면 앞 문단에 딸려 들어간다.
- 항목 안에 파이프(`|`)나 콜론(`:`)이 필요하면 다른 문자로 바꿔 적는다. 이스케이프는 지원하지 않는다.
- 세 컴포넌트 모두 위아래 여백 36px 을 스스로 갖는다. 앞뒤에 빈 줄을 더 넣을 필요는 없다.
