{%- comment -%} 글 카드. include.post 로 글 객체를 받는다. 요약은 subtitle을 우선 쓰고 없으면 본문 첫 문단에서 끊는다. 읽는 시간은 read_time 이 있으면 그 값, 없으면 한국어 분당 500자로 계산한다. {%- endcomment -%} {%- assign p = include.post -%} {%- assign summary = p.subtitle | default: p.excerpt | strip_html | strip_newlines | truncate: 140 -%} {%- if p.read_time -%} {%- assign read_time = p.read_time -%} {%- else -%} {%- assign chars = p.content | strip_html | strip_newlines | size -%} {%- assign read_time = chars | divided_by: 500 | plus: 1 | append: '분' -%} {%- endif -%}
{%- if p.tags.size > 0 %}
{%- for tag in p.tags %} {{ tag }} {%- endfor %}
{%- endif %}

{{ p.title }}

{{ summary }}

{{ p.date | date: "%Y.%m.%d" }} {{ read_time }}
